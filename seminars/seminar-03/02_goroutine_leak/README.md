# Утечка goroutine

Утечка goroutine — это задача, которая больше не приносит пользы, но никогда не завершается. Причина в начальном примере: worker ждёт сигнал бесконечно, а отправить его некому.

Для диагностики в демо используется `runtime.NumGoroutine()`. В реальном сервисе дополнительно смотрят goroutine profile: `net/http/pprof` или `go tool pprof`.

Исправление не в том, чтобы «убить goroutine», а в том, чтобы при запуске определить условие выхода. Здесь это закрытие `stop`: пока достаточно понимать его как сигнал «работа окончена».

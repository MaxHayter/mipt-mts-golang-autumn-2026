# Шаг 2: явный сигнал остановки

## Запуск

```bash
go run ./02_goroutine_leak/02_iteration
```

Ожидаемый результат близок к `goroutines: before=1, after=1`.

## Что сказать

- `stop` — минимальный сигнал «больше не работаем»; подробную механику каналов можно разобрать позднее.
- Закрытие `stop` будит все ожидающие goroutine, а `WaitGroup` подтверждает, что они действительно завершились.
- Исправление не «убивает» goroutine извне. Оно заранее задаёт ей нормальное условие выхода.

## Время

```bash
/usr/bin/time -p go run ./02_goroutine_leak/02_iteration
```

Важнее не время, а отсутствие роста числа goroutine после завершения работы.

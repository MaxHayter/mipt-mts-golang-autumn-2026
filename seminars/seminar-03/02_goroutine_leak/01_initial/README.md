# Шаг 1: goroutine без выхода

## Запуск

```bash
go run ./02_goroutine_leak/01_initial
```

Ожидаемый результат близок к `goroutines: before=1, after=101`.

## Что сказать

- Каждая из 100 goroutine ждёт значение из канала, но его никто не отправит.
- Программа завершится и runtime очистит всё вместе с процессом, но в долгоживущем сервере такие задачи будут накапливаться.
- Это утечка goroutine: работа больше не полезна, но не может завершиться.
- Минимальный вопрос перед каждым `go`: «при каком событии эта goroutine выйдет?»

## Время

```bash
/usr/bin/time -p go run ./02_goroutine_leak/01_initial
```

Время почти ничего не говорит об утечке. Здесь показатель — `runtime.NumGoroutine()`, а в сервисе — goroutine profile.

# Шаг 1: последовательный эталон

## Запуск

```bash
go run ./01_race_detector/01_initial
go run -race ./01_race_detector/01_initial
```

Ожидаемый результат: `count: 1000`. Race detector ничего не сообщает.

## Что сказать

- Здесь есть общая переменная `count`, но обращаться к ней некому одновременно: цикл и `count++` выполняются одной goroutine `main`.
- Это контрольный вариант. До добавления конкурентности программа корректна и предсказуема.
- Далее мы изменим только один фактор — добавим `go` перед функцией.

## Время

Можно показать, что `-race` добавляет диагностическую нагрузку:

```bash
/usr/bin/time -p go run ./01_race_detector/01_initial
/usr/bin/time -p go run -race ./01_race_detector/01_initial
```

В измерение входит компиляция, поэтому сравнение неточное. Здесь важнее корректность, а не скорость.

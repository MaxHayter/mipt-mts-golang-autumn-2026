# Шаг 2: копируем только нужные данные

## Запуск и профиль

```bash
go run ./03_memory_leak/02_iteration
go tool pprof -top memory-fixed.pprof
```

Ожидается `HeapAlloc` порядка долей MiB, а не 30 MiB.

## Что сказать

- `append([]byte(nil), buffer[:1]...)` создаёт новый массив ровно под нужный байт.
- После итерации `buffer` становится недостижимым, поэтому `runtime.GC()` может освободить его.
- Копирование иногда правильно: оно отделяет маленький результат от большого временного буфера.

## Время

```bash
/usr/bin/time -p go run ./03_memory_leak/02_iteration
```

Небольшая цена копирования оправдана, когда иначе удерживается большой объём памяти.

# Утечка памяти: удержание backing array

Это не «утечка» в смысле потерянного указателя: сборщик мусора не освобождает память, потому что на большой массив всё ещё есть ссылка. В начальном примере в cache сохраняется один байт из каждого 1 MiB буфера, но subslice удерживает весь буфер.

Сначала сравните `HeapAlloc`, затем откройте профиль командой `go tool pprof -top memory-initial.pprof`. В исправлении копируется только нужный байт, поэтому большой буфер после итерации становится недостижимым для GC.
